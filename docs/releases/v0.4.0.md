Revo is a tiny native macOS desktop companion with a tactile paper-shredder interaction. Files move to macOS Trash and remain recoverable.

### In this release

- A silver and liquid-glass paper-shredder app icon, with a sheet entering the slot and visible cut paper ribbons.
- A universal DMG with a Retina installation layout and an Applications shortcut.
- A rounded metal head, clear glass enclosure, soft reflections, a tactile mint power switch, and a daily file counter.
- File-specific feeding and cutting animations, with loose paper that sways and rustles when the machine moves.
- A resident menu bar icon, a customizable global shortcut, and six interface languages: English, Simplified Chinese, Japanese, Korean, Russian, and French.
- A default-off safety switch, recoverable Trash operations, and conflict-safe undo of the last file in the current session.

### Install

Requires **macOS 14 or later**. The universal app supports **Apple silicon and Intel**.

1. Download `Revo-0.4.0-universal.dmg`.
2. Open the disk image and drag Revo to Applications.
3. Open Revo from Applications. Its power switch starts off.

The default show/hide shortcut is **Control + Option + R**. Right-click Revo for language, sound, and shortcut settings. Click its menu bar icon to bring the desktop machine back.

### Signing

This build has an **ad-hoc signature**, not a Developer ID signature, and **has not been notarized by Apple**. macOS may block its first launch. See [Apple's guidance for opening downloaded apps](https://support.apple.com/en-us/102445). Revo does not disable or change Gatekeeper settings.
