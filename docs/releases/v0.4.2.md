# Revo 0.4.2

Revo has a rounded geometric app icon and sky-blue accents, with the original italic lettering preserved on the machine. This release also introduces the clean-gradient product demo and a short logo entrance animation.

## Changes

- Updated the app icon with a bold, rounded lowercase wordmark and a small opening in the e.
- Kept the machine's original Georgia Italic Revo lettering.
- Added sky-blue tones to the powered switch, counter display, and built-in photo and audio previews. Actual image thumbnails retain their original colors.
- Replaced the README preview with the clean-gradient interaction animation, including document and photo feeding, shredding, movement, and shaking.
- Added the [full demo with sound](https://github.com/zhanglily99/revo/releases/download/v0.4.2/Revo-Demo.mp4) and [logo entrance](https://github.com/zhanglily99/revo/releases/download/v0.4.2/Revo-Logo-Entrance.mp4) as release downloads.

## Install or update

Version **0.4.2**, build **29**. Requires **macOS 14 or later**. One universal app supports **Apple silicon and Intel**.

1. Quit an existing Revo instance.
2. Download and open `Revo-0.4.2-universal.dmg`.
3. Drag Revo to Applications and replace the previous copy if prompted.
4. Open Revo from Applications. Its power switch starts off.

The app identifier remains the same, preserving existing preferences and custom shortcuts.

## Signing and verification

This build has an **ad-hoc signature** and **has not been notarized by Apple**. macOS may block its first launch. See [Apple's guidance for opening downloaded apps](https://support.apple.com/en-us/102445).

The disk image, packaged app signature, both architecture slices, bundled license, and Applications shortcut passed verification. `SHA256SUMS.txt` contains checksums for the release downloads.

The app's self-test passed checks for shortcut conflicts and persistence, shaking strength and settling, fragment bounds, the default-off interlock, rejected drops, queue cancellation, file classification, recycling, restoration, conflict protection, and missing-file handling. Runtime checks ran on Apple silicon; the Intel slice was cross-compiled and structurally verified.
