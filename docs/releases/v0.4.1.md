Revo 0.4.1 keeps the file-shredding interaction free of bottom captions.

### Changes

- Removed the bottom text during normal drag, feeding, shredding, demonstrations, and completion. Animations, sound, and the counter provide feedback.
- Preserved safety warnings and feedback for failed operations.
- Added a [looping interaction demonstration](https://github.com/zhanglily99/revo#readme) to the project introduction, showing power controls, paper feeding and cutting, movement, and loose-paper inertia.

### Install or update

Requires **macOS 14 or later**. One universal app supports **Apple silicon and Intel**.

1. Quit an existing Revo instance.
2. Download and open `Revo-0.4.1-universal.dmg`.
3. Drag Revo to Applications and replace the previous copy if prompted.
4. Open Revo from Applications. Its power switch starts off.

Preferences continue to use the same app identifier. The default show/hide shortcut is **Control + Option + R**, and an existing custom shortcut remains available.

### Signing and integrity

This build has an **ad-hoc signature**, not a Developer ID signature, and **has not been notarized by Apple**. macOS may block its first launch. See [Apple's guidance for opening downloaded apps](https://support.apple.com/en-us/102445).

The DMG, its packaged app signature, both architecture slices, bundled license, and Applications shortcut are verified during packaging. `SHA256SUMS.txt` contains checksums for the DMG and attached license. Runtime checks were performed on Apple silicon; Intel was cross-compiled.
